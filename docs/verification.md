本地启动数据库及应用后运行 `npm run test:integration`。默认应用地址为 `http://localhost:3036`，可用 `TEST_BASE_URL` 覆盖；测试所用数据库必须与目标应用一致。

服务器已保存最新验收脚本 `/opt/event-qna/integration.ts`，可执行：

```sh

```
